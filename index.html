deal POS — Privacy Policy

deal is a point-of-sale application that runs on the store's own computer.

If the store owner chooses to link Google Drive, deal uses the "drive.file" permission only. It can create and read only the backup files it creates itself, in a folder named "deal-backups" in the user's own Google Drive. It cannot see any other files.

Backups are encrypted on the computer with a password chosen by the store owner before they are uploaded.

deal does not send this data to the developer or to any third party, and it does not sell or share any data.

The user can unlink at any time from the app's settings, or from https://myaccount.google.com/permissions
